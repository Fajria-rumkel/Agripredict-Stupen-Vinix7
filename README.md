# AgriPredict - Projek Akhir Stupen VINIX7

Projek akhir kelompok untuk divisi **Python Data Science Engineer** di program Studi Independen VINIX7. 

Projek ini fokus membuat dashboard interaktif menggunakan Streamlit untuk memprediksi estimasi hasil panen pertanian dan simulasi perhitungan keuntungan petani berdasarkan data cuaca serta luas lahan (studi kasus wilayah Cangkringan).

## 📌 Fitur Utama (On Progress)
- **Prediksi Panen**: Perkiraan hasil panen komoditas berdasarkan luas lahan & waktu tanam.
- **Kalkulator Keuntungan**: Estimasi pendapatan dan profit bersih petani.
- **Visualisasi Cuaca**: Grafik tren curah hujan & hari hujan bulanan.

---

## 📁 Struktur Folder
- `data/raw/` : Tempat simpan file data mentah.
- `data/processed/` : Data yang sudah dibersihkan.
- `notebooks/` : Notebook Jupyter buat cleaning data, EDA, dan eksperimen model ML.
- `src/` : Script Python pendukung (pipeline data & model).
- `app.py` : Script utama untuk nampilin dashboard Streamlit.
